# Аким на 5 часов — React frontend

React + TypeScript + Vite. Нужны Node.js 22.18+ (или 24+) и работающий Python API.
Полный запуск двумя терминалами описан в [корневом README](../README.md).

Из `ui/`:

```powershell
npm ci
npm run dev
```

Откройте http://localhost:5173. API по умолчанию: http://localhost:8000.
При необходимости задайте `VITE_API_URL` в `.env.local` по образцу `.env.example`.
Адрес frontend должен совпадать с серверным `FRONTEND_ORIGIN`.
OpenAI key хранится только в окружении Python, никогда в `VITE_*`.

## Поток данных

- `GET /api/catalog` поставляет районы, показатели, Score, инициативы, эффекты,
  цены, лаги, веса и ограничения из engine. `src/data/catalog.ts` содержит только
  русские подписи и описания для отображения.
- Кнопка запуска передаёт только `decisions` в `POST /api/simulate`.
  Окончательная валидация принадлежит Python. UI показывает сообщения engine.
- Результат отображает Score, дельты, бюджет, критические показатели, слабейший
  район, сравнение до/после и сработавшие синергии из API, с двумя знаками.
- Отдельная кнопка AI передаёт те же решения в `POST /api/analyze`.
  Сервер заново рассчитывает сценарий перед анализом. AI-ошибка не скрывает результат.
- Выбор хранится в памяти вкладки. Изменение решений очищает результат и анализ,
  отменяет ожидание текущего запроса. Перезагрузка страницы сбрасывает сценарий.

Frontend проверяет заполнение слотов и показывает стоимость по серверному каталогу.
Формул Score, lag scaling, clipping, синергий и несовместимостей в React нет.
Число критических показателей приходит из API. Radar — описательное невзвешенное
среднее baseline-индикаторов направления; метод явно указан на диаграмме.
Цветовые уровни карты являются оформлением, а не дополнительными правилами engine.

«Демо-сценарий» заполняет эталонные решения без автоматического запуска API/AI:
M7, M8, M10 → Nura; M12 → city; M5 → Saryarka.

## Структура

- `src/api/client.ts`, `types.ts`: fetch, проверка формы ответа, типы и ошибки.
- `src/api/CatalogContext.tsx`: каталог сервера с русскими подписями.
- `src/hooks/useScenario.ts`: симуляция, явный AI-запрос, loading и очистка состояния.
- `src/App.tsx`: загрузка каталога, выбор решений и сборка экрана.
- `src/components/Overview.tsx`, `CityRadar.tsx`, `Initiatives.tsx`: исходный dashboard.
- `src/components/Results.tsx`: результат, сравнения, валидация и AI-анализ.
- `src/utils/presentation.ts`: только форматирование и описательная метрика радара.
- `src/styles/results.css`: стили нового раздела в палитре существующего frontend.

## Проверки

```powershell
npm test
npm run typecheck
npm run build
```

Fixtures тестов получаются из настоящего engine через FastAPI TestClient без HTTP
сервера. Нужны установленные Python-зависимости из `../requirements.txt`.
Python выбирается из `PYTHON`, корневого `.venv` или PATH. Проверяются контракт,
fetch-ошибки, React-разметка эталона, loading, валидация и AI с подменённым ответом.
Настоящие OpenAI-запросы не выполняются. SSR-проверки не заменяют визуальную
проверку и клики в браузере перед демонстрацией.

`npm run preview` использует другой origin; для него задайте соответствующий
`FRONTEND_ORIGIN` при запуске API. Меню сравнения сценариев пока не подключено.
Локальные CSS/Lucide иллюстрации сохранены, внешние изображения не загружаются.
